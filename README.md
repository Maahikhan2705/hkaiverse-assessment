## Overview

This repository contains both assessment tasks and their supporting
materials. The work focuses on practical process improvement,
evidence-based analysis, responsible use of AI, and future-ready
curriculum design.

## Task 1 --- PlacementHub Workflow Investigation and Redesign

This task examines a placement-related workflow, maps the main steps and
responsibilities, and identifies process risks and opportunities for
improvement.

Key areas covered: - Workflow steps, hand-offs, roles, and status
definitions. - The distinction between an application action and a
verified application outcome. - Proposed improvements, including an
advisory AI-assisted resume/job-description compatibility feature. -
Synthetic acceptance tests for normal and edge-case scenarios. - An
illustrative impact model, risks, controls, and an implementation plan.


## Task 2 --- Curriculum Redefinition for 2030

This task reviews the supplied B.Tech Artificial Intelligence and Data
Science course map and proposes practical changes to strengthen
readiness for AI, data science, and software engineering roles by 2030.

Key areas covered: - Review of the supplied course map and its evidence
basis. - Course-level recommendations that retain core foundations while
strengthening practical outcomes. - A proposed redesign affecting 39
credits out of a 166-credit working baseline (23.5%), subject to
confirmation against the applicable batch regulation. - A proposed AI
Systems Engineering Lab/Capstone and AI-assisted subject exercises. -
Validation and feedback planning, success indicators, and an
implementation roadmap.
